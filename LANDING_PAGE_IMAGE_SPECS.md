# Landing Page Image Design Specifications

## Overview

Professional design specifications for two key conversion-focused images on the LLM.txt Mastery landing page. These images support the core value proposition of "73% more AI citations" and competitive advantage messaging.

---

## IMAGE 1: Hero Illustration - "Before/After AI Discovery"

### Technical Specifications

- **Dimensions**: 800px × 400px (2:1 aspect ratio)
- **File Format**: SVG (preferred) or WebP/PNG with high DPI
- **File Size**: <200KB optimized
- **Usage**: Above-the-fold hero section, critical for first impression
- **Responsive**: Must scale cleanly from 320px to 1200px+ width
- **Accessibility**: Alt text: "Website transformation from invisible to AI-discoverable"

### Layout Structure

**Split-screen design with center bridge element:**

- **Left Panel (380px)**: "BEFORE" state - Invisible to AI
- **Center Bridge (140px)**: LLM.txt transformation connector
- **Right Panel (380px)**: "AFTER" state - Discovered by AI

### Color Palette

```
Primary Brand Colors:
- Innovation Teal: #00A6C7 (primary brand color)
- Framework Black: #1F2937 (text)
- AI Silver: #6B7280 (secondary text)

Before State (Left):
- Background: #E2E8F0 (cool gray)
- Website icon: #94A3B8 (muted)
- AI logos: #6B7280 (disabled gray)
- X marks: #EF4444 (red)
- Text: #64748B (muted text)

Bridge Element:
- Background: #F97316 (orange)
- Border: #EA580C (darker orange)
- Text: #FFFFFF (white)

After State (Right):
- Background: Linear gradient #DCFCE7 to #BBF7D0 (green)
- Website icon: #10B981 (success green)
- AI logos: #10B981 (active green)
- Arrows/checks: #10B981 (success indicators)
- Text: #047857 (dark green)
- Glow effects: #10B981 at 40% and 60% opacity

Top Banner:
- Background: #F97316 (orange)
- Border: #EA580C (darker orange)
- Text: #FFFFFF (white)
```

### Typography Specifications

- **Main Headlines**: Sans-serif, 28px, Bold (700 weight)
  - "INVISIBLE TO AI" / "DISCOVERED BY AI"
- **Banner Text**: Sans-serif, 18px, Bold (700 weight)
  - "🚀 73% MORE AI CITATIONS"
- **Subtext**: Sans-serif, 14px, Medium (500 weight)
  - "Get Found in 24 Hours, Not 24 Months"
- **AI Platform Labels**: Sans-serif, 14px, Medium (500 weight)
  - "ChatGPT", "Claude", "Perplexity"
- **Bridge Text**: Sans-serif, 14px, Bold (700 weight)
  - "LLM.txt BRIDGE"

### Visual Elements Detail

#### Left Panel - "BEFORE" State

- **Website Icon**: 100×80px rounded rectangle (12px radius), grayed out with content lines
- **AI Platform Logos**: 25px radius circles with letter abbreviations
  - ChatGPT: "GPT" in circle
  - Claude: "C" in circle
  - Perplexity: "P" in circle
- **Disconnection Indicators**: Red X marks (4px stroke weight) showing AI platforms can't see website
- **Overall Mood**: Muted, disconnected, problematic

#### Center Bridge Element

- **Bridge Box**: 140×60px rounded rectangle (8px radius)
- **Visual Flow**: Arrows (4px stroke) pointing from left to right through bridge
- **Purpose**: Clear visual connector showing transformation process

#### Right Panel - "AFTER" State

- **Website Icon**: Same as left but highlighted in success green with glow effects
- **Double Glow Rings**: 60px and 80px radius circles around website (3px and 2px strokes)
- **AI Platform Logos**: Same layout but active green showing engagement
- **Connection Arrows**: Green arrows (4px stroke) pointing toward website
- **Success Checkmarks**: Green checkmarks showing successful discovery
- **Overall Mood**: Vibrant, connected, successful

#### Top Banner Element

- **Positioning**: Centered, 15px from top edge
- **Content**: Rocket emoji + "73% MORE AI CITATIONS"
- **Visual Priority**: Most prominent element for immediate impact

### Content Hierarchy (Visual Weight)

1. **Primary**: "73% MORE AI CITATIONS" banner (highest contrast)
2. **Secondary**: "INVISIBLE TO AI" / "DISCOVERED BY AI" headlines
3. **Tertiary**: LLM.txt BRIDGE connector
4. **Supporting**: AI platform logos and connection indicators

### Key Design Principles

- **Emotional Journey**: Clear before/after transformation story
- **Visual Contrast**: Stark difference between left (problem) and right (solution)
- **Credible Branding**: Use recognizable AI platform visual cues
- **Conversion Focus**: Orange elements draw attention to solution
- **Professional Polish**: Clean, modern SaaS aesthetic

## Implementation Guidelines

### File Delivery Requirements

1. **Primary files**: SVG format for infinite scalability
2. **Fallback files**: WebP format at 2x resolution (1600×800px and 1600×640px)
3. **Legacy support**: PNG format at 2x resolution if needed
4. **Optimization**: All files compressed for web delivery

### Quality Assurance Checklist

- [ ] Text remains readable at 320px viewport width
- [ ] Colors meet WCAG AA contrast requirements (4.5:1 minimum)
- [ ] All text uses web-safe fonts or includes font files
- [ ] File sizes under specified limits
- [ ] SVG code is clean and optimized
- [ ] Visual hierarchy supports conversion goals
- [ ] Consistent with overall brand aesthetic

### Usage Context

- **Hero Image**: Critical first impression, drives initial engagement
- **Process Image**: Builds credibility and explains competitive advantage
- **Conversion Impact**: Both images directly support "10x better AI discovery" messaging
- **Mobile Optimization**: Must work effectively on small screens where most traffic occurs

### Success Metrics

These images should contribute to:

- Increased time on page (better engagement)
- Higher scroll depth (visual interest)
- Improved conversion rates (clearer value proposition)
- Reduced bounce rate (immediate visual appeal)
