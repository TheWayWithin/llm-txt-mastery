## Pricing Philosophy

**Core principle**: Every tier delivers genuine value. Paid tiers are earned through demonstrated value, not manufactured limitation. The product proves itself before asking for money.

**Pricing Principles (from Unified Strategy):**

1. **Accessibility over extraction** -- Every tier is priced for the solopreneur and small business owner, not enterprise budgets.
2. **Value before gate** -- Free tiers deliver genuine insight. The product proves itself before asking for money.
3. **Transparency as trust** -- Our methodology is published. Our pricing is permanent. No countdown timers or expiring offers.
4. **Growth as gravity well** -- The entire value ladder is designed so Growth is the most natural tier for serious users.
5. **Loop completeness rewards commitment** -- Higher tiers complete the Diagnose-Optimize-Test-Repeat loop.

**Risk Reversal:**
- **No credit card required** for Free tier (zero friction entry)
- **30-day money-back guarantee** on all paid tiers (zero risk)

## Marketing Physics

*Based on Doug Hall's Marketing Physics: Dramatic Difference, Overt Benefits, Real Reasons to Believe*

### Dramatic Difference

**The Category:** AI-powered llms.txt generation with content intelligence and quality scoring.

**The Quality Moat:** Free generators produce identical descriptions for every page. LLM.txt Mastery reads each page, understands the content, and generates unique descriptions with a quality score (0-10 float). On angular.dev, the leading free tool (Keploy) found 1,499 pages all with the same description: "The web development framework for building modern apps." LLM.txt Mastery found 1,000 pages, each with unique AI-generated descriptions, quality scores, and content intelligence metrics.

**The Architecture:** AI content analysis with 5 discovery strategies (sitemap.xml, robots.txt, homepage links, basic crawl, deep crawl), auto-selection with >=5 quality threshold, framework detection with coverage warnings, and a validator that scores content quality -- the only one that does.

### Overt Benefits

**Primary:** "Help AI understand what your business actually does -- page by page, scored for quality."

**Supporting Benefits:**
- Content-aware descriptions that reflect what each page actually says (vs generic boilerplate)
- Quality scoring (0-10 float) showing which descriptions are strong and which need work
- Content intelligence metrics: code examples, tables, structured items counted per page
- Framework detection with transparency warnings (coverage estimation for JS-heavy sites)
- Validator with quality scoring and robots.txt conflict detection

### Real Reasons to Believe

| Proof Point | Evidence |
|---|---|
| **Quality scoring** | 0-10 float scale per page -- verifiable by running any analysis |
| **Content intelligence** | Code examples, tables, structured items counted -- visible in output |
| **Framework detection** | 8+ frameworks detected with coverage warnings -- testable on any JS site |
| **Validator** | Only validator that scores content quality, not just file existence |
| **Head-to-head test data** | angular.dev: 1,000 unique descriptions vs Keploy's 1,499 identical ones |

### Five Verified Competitive Moats

1. **AI-Generated Unique Descriptions** -- Per-page content analysis vs identical boilerplate
2. **Quality Scoring** -- 0-10 float scale per entry, no competitor offers this
3. **Content Intelligence** -- Code examples, tables, structured items counted
4. **Framework Detection + Transparency** -- Coverage warnings, not just silent gaps
5. **Validator with Quality Scoring** -- Only validator that scores how good the file is, not just if it exists

**What is NOT a competitive advantage:**
- JavaScript rendering (Keploy has it too)
- Page discovery quantity (Keploy found 49.9% more on angular.dev)

## Upgrade Triggers

### Design Principles

1. **Value before gate** -- User must have experienced measurable value before seeing an upgrade prompt
2. **Behaviour-based, not time-based** -- Triggers activate on usage patterns, not arbitrary calendars
3. **Explicit permission to stay** -- Every message validates the current tier
4. **Incremental framing** -- Present price as delta from current spend, not absolute
5. **Specificity over superlatives** -- Name exact features gained, never "unlock premium features"
6. **No manufactured urgency** -- No countdown timers, no "limited spots," no expiring offers
7. **Math that checks out** -- Every percentage and comparison must be mathematically verifiable

### Trigger Messages

#### Free -> Solo ($0 -> $4.95/mo)

**Trigger:** User reaches 3rd free analysis and attempts a 4th, or analyses a site exceeding 20 pages.

**Message:**
> "You've used all 3 free analyses this month. Your results so far are yours to keep. Solo is $4.95/mo -- less than a coffee -- with 200 pages and 20 analyses per month. No pressure -- your free analyses reset next month."

#### Solo -> Growth ($4.95 -> $9.95/mo)

**Trigger:** User regularly analyses multiple sites, or attempts Growth-tier features (bulk, export).

**Message:**
> "You're managing multiple sites on Solo -- that tells us you're getting real value. Growth is $5 more per month with 35 analyses, bulk processing, and export. Everything you have stays the same."

#### Growth -> Scale ($9.95 -> $19.95/mo)

**Trigger:** User consistently hits Growth limits, or manages sites for clients (multiple distinct domains).

**Message:**
> "You're analysing [X] sites across [Y] domains. Scale includes JS rendering, API access, and 100 analyses/month. At $19.95/mo, that's under $0.67/day. If Growth is working well, stay on it -- Scale is here when the volume demands it."

### Cross-Product Trigger: LLM.txt -> AImpactScanner Growth

**Trigger:** User completes an llms.txt optimization and sees prompt about the other 26 factors.

**Message:**
> "Your llms.txt file scores [X]/10 -- that's strong. But llms.txt is 1 of 27 factors that determine whether AI recommends your business. AImpactScanner Growth ($19.95/mo) scans all 27 factors and includes LLM.txt Growth free -- your optimization tools carry over. You fixed the file. Now see the full picture."

**For users on LLM.txt Growth ($9.95/mo):**
> "AImpactScanner Growth is $19.95/mo and includes everything in your current LLM.txt Growth plan. The effective cost of adding the full 27-factor diagnostic engine is $10/mo."

### In-App Upgrade Rules

- Maximum 1 upgrade prompt per session (don't nag)
- Always show what they GET, not what they DON'T have
- Include the price to reduce friction ("Just $4.95/mo")
- Show the guarantee ("30-day money-back, no questions asked")
- Never fire before the user has completed at least one successful analysis

## Competitive Response Playbook

### When Keploy Is Mentioned

**Objection:** "Keploy is free and finds more pages. Why would I pay?"

**Response framework:**
- Acknowledge the page count honestly. Keploy found 49.9% more pages on angular.dev.
- Then ask: what did those pages contain? The same description on all 1,499 pages.
- Frame the choice: free tool that generates volume vs $4.95/mo tool that generates intelligence.
- Structural point: Keploy is an AI testing company. Their llms.txt generator is a marketing expense, not a product with ongoing investment.

**What NOT to say:** Don't claim we find more pages. Don't claim JS rendering exclusivity against Keploy. Don't disparage their core testing product.

### When Enterprise Tools Are Mentioned

**Objection:** "Why not just use Semrush/Ahrefs?"

**Response framework:**
- Acknowledge their strengths in traditional SEO.
- Distinguish: retrofitting AI features onto Google-era tools vs purpose-built for AI search.
- Methodology transparency: we publish ours, they hide theirs.

## Objection Handling

### "Why pay when free tools exist?"

**Response:** Try the free tools. Compare the output side by side. Free tools generate identical descriptions for every page. We read each page, understand the content, and score quality on a 0-10 scale. The difference is visible in 30 seconds.

### "I can do this manually"

**Response:** You absolutely can. We publish the MASTERY-AI Framework so you can apply it yourself. The tool saves you hours on multi-page sites, adds quality scoring you can't do manually, and keeps files current as content changes. If you have fewer than 10 pages and enjoy the process, manual is fine.

### "I'll wait until the space matures"

**Response:** Reasonable position. AI visibility compounds -- businesses that optimise early build citation advantages that self-reinforce. The free scan doesn't expire. Neither does the 25% annual discount. We'll be here when the timing is right.
