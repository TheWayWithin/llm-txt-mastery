### 🐛 Issues & Learnings

#### Issue: Drizzle ORM Relations Import Error
- **Root Cause**: `relations` function was imported from `drizzle-orm/pg-core` instead of `drizzle-orm`
- **Fix**: Moved import to correct package: `import { relations } from 'drizzle-orm'`
- **Prevention**: Always check Drizzle documentation for correct import paths when using relations
- **Time Impact**: ~15 minutes

#### Issue: TypeScript Type Errors in API Routes
- **Root Cause**: Express Request type didn't include custom `apiKey` property added by middleware
- **Fix**: Extended Express Request interface with proper type declaration
- **Prevention**: Create type declarations upfront when extending framework interfaces
- **Time Impact**: ~10 minutes
